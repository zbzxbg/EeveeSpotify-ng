> [!WARNING]
> **This repository has been archived. EeveeSpotify-ng is no longer maintained.**
>
> The reason is simple: during testing on Spotify 9.1.86, EeveeSpotifyEvolved has largely resolved the issue where some lyrics are not displayed in the lyrics module. I also don't have enough time or energy to maintain two EeveeSpotify projects at the same time 😢. So, you get the idea.
>
> Therefore, EeveeSpotify-ng-9.1.0 will no longer be updated, even though the following known issues remain:
>
> <details>
> <summary>Known issues that will not be fixed</summary>
>
> - After the Genius fallback is triggered, the lyrics source still displays as the primary lyrics source.
> - PetitLyrics:
>   - Cannot correctly handle abnormal word-by-word lyric timings.
>   - Cannot correctly handle the timings of some lyrics.
> - NetEase:
>   - Cannot correctly romanize some Japanese.
>   - Cannot correctly handle lyric translations.
>   - Cannot correctly handle the timings of some lyrics.
> - Musixmatch:
>   - Cannot correctly handle the timings of some lyrics.
>
> </details>
>
> Please consider using [EeveeSpotifyEvolved](<link>) instead.
